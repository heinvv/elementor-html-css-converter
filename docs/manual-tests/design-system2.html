02 — Component

.ds-card

Surface Container

Cards group related content inside an elevated surface. Hover to see the border transition to accent color, paired with a lifted shadow.

Flexible Usage

Drop any content inside — stats, forms, text, images. The card constrains padding and border-radius via design tokens so every instance stays consistent.
