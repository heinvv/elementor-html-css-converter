# Global Classes Import API

Import CSS class definitions into Elementor's Global Classes system.

## Endpoint

```
POST /wp-json/html-css-converter/v1/import-classes
```

## Request Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `css` | string | Yes* | - | CSS string containing class definitions |
| `url` | string | Yes* | - | URL to fetch CSS from |
| `update_mode` | string | No | `create_new` | `create_new` or `update` |
| `context` | string | No | `frontend` | `frontend` or `preview` |

*Either `css` or `url` must be provided

## Update Modes

| Mode | Behavior |
|------|----------|
| `create_new` | Skip if identical class exists. If same name but different styles, create with suffix (`-2`, `-3`) |
| `update` | Overwrite existing class with same label |

## Example Request

```bash
curl -X POST http://your-site.com/wp-json/html-css-converter/v1/import-classes \
  -H "Content-Type: application/json" \
  -d '{
    "css": ".btn-primary { color: #ffffff; background-color: #007bff; padding: 10px 20px; } .card { border-radius: 8px; }",
    "update_mode": "create_new"
  }'
```

## Error Responses

### Missing Input (400)
```json
{
  "error": "Missing css or url",
  "code": "invalid_request"
}
```

### Empty CSS (422)
```json
{
  "error": "Empty CSS",
  "code": "empty_css"
}
```

### No Classes Found (422)
```json
{
  "error": "No classes found in CSS",
  "code": "no_classes"
}
```

### Fetch Error (502)
```json
{
  "error": "Fetch failed",
  "code": "fetch_error",
  "details": "Connection timeout"
}
```

## Edge Cases

| Scenario | Behavior |
|----------|----------|
| **100 global class limit** | Returns partial success with `overflow` array containing excess classes |
| **Duplicate class (same styles)** | Reuses existing class silently |
| **Duplicate class (different styles)** | Creates new with suffix `-2`, `-3`, etc. (in `create_new` mode) |
| **Label > 50 characters** | Truncates label and adds warning |
| **Unsupported CSS property** | Stored in `custom_css` field |
| **Compound selector `.a.b`** | Skipped (cannot map to single global class) |
| **Elementor internal class** | Skipped (`e-con-*`, `elementor-*`, `e-*` prefixes) |
| **CSS variables `var()`** | Resolved using existing variable resolver (same as HTML/widget endpoints) |
| **`!important` flag** | Stripped from value |
| **Same class in multiple rules** | Properties merged (last wins) |
| **ID selectors `#id`** | Skipped |
| **Element selectors `div`** | Skipped |
| **Pseudo-classes `:hover`** | Skipped (MVP) |
| **Media queries `@media`** | Skipped - desktop only (MVP) |

## Supported CSS Properties

The endpoint supports the same CSS properties as the existing `/css-to-atomic` endpoint:

### Colors & Background
- `color`
- `background-color`

### Layout & Spacing
- `padding`, `padding-top`, `padding-right`, `padding-bottom`, `padding-left`
- `margin`, `margin-top`, `margin-right`, `margin-bottom`, `margin-left`
- `width`, `height`
- `display`, `position`
- `gap`

### Flexbox
- `flex-direction`, `flex-wrap`, `flex`
- `justify-content`, `align-items`, `align-content`, `align-self`
- `flex-grow`, `flex-shrink`, `flex-basis`
- `order`

### Typography
- `font-size`, `font-weight`, `font-style`
- `text-align`, `line-height`, `letter-spacing`, `word-spacing`
- `text-decoration`, `text-transform`

### Visual
- `border-radius`
- `box-shadow`, `text-shadow`
- `opacity`
- `border`, `border-width`, `border-style`, `border-color`
- `transform`
- `top`, `right`, `bottom`, `left`

Unsupported properties are collected in the `custom_css` field.

## Global Class Structure

Classes are stored in Elementor's Kit document with this structure:

```php
[
    'id' => 'g-123',           // Auto-generated by Elementor
    'type' => 'class',
    'label' => 'btn-primary',  // From CSS class name
    'variants' => [
        [
            'meta' => [
                'breakpoint' => 'desktop',
                'state' => null
            ],
            'props' => [
                'color' => ['$$type' => 'color', 'value' => '#fff'],
                'padding' => ['$$type' => 'dimensions', 'value' => [...]]
            ],
            'custom_css' => null
        ]
    ]
]
```

## Verification

After importing, verify classes appear in:
1. Elementor Editor > Site Settings > Global Classes
2. Any widget's Style tab > Class dropdown
