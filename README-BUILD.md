# Build Instructions

This plugin uses TypeScript/TSX with webpack for compilation.

## Prerequisites

- Node.js (v16 or higher)
- npm or yarn

## Setup

1. Install dependencies:
```bash
npm install
```

## Development

Watch mode (auto-rebuild on file changes):
```bash
npm run dev:editor
```

## Production Build

Build for production:
```bash
npm run build:editor
```

## File Structure

- **Source files**: `assets/js/src/editor/` (TSX files)
- **Compiled files**: `assets/js/editor/` (JS files - generated by webpack)
- **Type definitions**: `assets/js/src/types/`

## Notes

- The compiled `import-modal-react.js` file is automatically generated from `import-modal-react.tsx`
- Do not edit the compiled JS file directly - edit the TSX source file instead
- After making changes to TSX files, run the build command to compile
